How an LLM answers a question

6Response, one token at a time

↻ Each new token is appended to the input and the whole input runs again, until the model emits <end>

1Tokenizer → 2Token IDs Text splits into tokens; each token becomes its number in the vocabulary

3Transformer (neural network)

Attention lets every token look at the others, then every possible next token gets a score

Blue on the tokens above = how much the last token looked at each one (averaged over all layers and heads). The first token soaks up most attention in almost every model (an "attention sink"), so it is left off the scale.

4Softmax: probability of each next token

Scores become probabilities. The model picks one. Click a bar to pick it yourself.

5Detokenizer ID back to text
